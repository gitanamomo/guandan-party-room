## 目录约定

- `client/`、`server/`、`shared/`、`drizzle/`：当前运行源码，禁止放历史副本。
- `docs/records/`：验收记录、美术资产清单、建议报告和任务清单。
- `docs/versions/`：需要保留的版本说明、迁移说明或人工归档文档；源码历史通过 Git 管理。
- `scripts/`：当前仍可能复用的验证脚本。
- `scripts/archive/`：一次性演示、历史验证和数据种子脚本，默认不要执行。
- `drizzle/*.sql`：数据库迁移必须全部保留并按编号顺序执行，不要移动或重命名。

## 读取规则

1. 开发和修复只读取根目录当前源码，不读取 `scripts/archive/` 作为业务实现。
2. 判断历史功能时先看本文件，再用 `git show <commit>:<path>` 查看历史提交。
3. 运行验收优先使用 `scripts/verify_four_player_online.ts`；归档脚本除非明确需要，不要运行。
4. 数据库迁移按 `0000` 至最新编号顺序维护，不能把迁移SQL当作旧版本源码删除。
