# GINA 牌友会 · v1.5 视觉重建计划

## 审核结论

v1.4 功能验证通过不等于画面达标。现有四足立绘与扁平背景、卡片式座位彼此割裂：角色未坐到桌边；四人座位未形成对坐关系；移动端将四席挤在同一横排；透视、接触阴影与材质光照不统一；主场景和手牌区割裂，页面更像信息面板。

## 视觉方向

拟人宠物花园会所，精致 3D 动画电影质感。保留橘色加菲、黑色贵宾、粉色斯芬克斯、黑色法斗的辨识特征，重新设计穿衣、坐椅、用爪持牌的角色。统一暖金日光与青绿色环境光。木纹桌沿、织物绒面、磨砂金属与纸牌厚度均需清楚但不抢牌面。

## 构图约束

- 相机固定，轻俯视约30度，正常焦距；不使用鱼眼、拼接透视或俯瞰地图视角。
- 掼蛋：近侧稍偏左的前景为我、远侧为对家、左右为对手；前景侧移用于保留桌心，四席围桌；所有角色面向桌心。
- 斗地主：近侧为我、远侧两席为对手，不能残留第四只角色或错误搭档席。
- 角色、椅子、桌面与环境一起构图，具备正确遮挡和接触阴影。
- 桌心保留动态出牌区，不在美术图内绘制假牌型、数字、按钮和状态。
- 状态标签贴近真实角色位置；手牌区与场景底部连成同一游戏界面。
- 手机端保持自身/对手的空间关系，不把全部人物改排成头像列表。全场景适配，不能以裁切牺牲角色。

## 实施阶段及验收

1. 视觉审核与规范：记录问题、锁定角色、镜头、材质和三/四人座位关系。
2. 完整效果图：制作正式风格场景，逐项审核角色解剖、持牌、透视、遮挡和动态牌区；不合格先修图。
3. 页面实现：保留规则引擎，重做场景、HUD、纸牌与操作条；三页面共享视觉逻辑。
4. 验收：桌面与手机截图人工审核 + 对局/联机回归；图像、规则、交互分别记录结果。未达标不以“测试通过”代替美术验收。
