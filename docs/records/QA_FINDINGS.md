# 本地回归验收记录

本次重点回归了房主登录/入房身份和四人在线开局链路。根因是创建房间后大厅把浏览器 `gd_guest_id` 写成了随机访客ID，而数据库房主席位使用 `host_<hostUserId>`；房主进入房间时找不到自己的0号位，点击入座后又占用了1号位，导致无法凑齐四人。

修复后，创建接口返回 `hostGuestId`，大厅保存该ID；服务端入座接口即使收到旧版随机房主访客ID，也会按房主账号匹配0号位并拒绝重复占位。实测房主加三位牌友后，四席分别为0、1、2、3，房间状态为 playing，四家均为27张牌。

浏览器截图已确认大厅可以正常加载，房间安全设置显示在创建表单；四人回归房间可正常进入牌桌，昵称、人物和手牌均正常显示。
